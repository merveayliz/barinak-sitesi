## 📖 Proje Hakkında / About
**TR:** Barınak Sitesi, sahipsiz hayvanların sıcak bir yuvaya kavuşmasına aracılık etmek, ziyaretçileri barınak faaliyetleri hakkında bilgilendirmek ve sahiplenme sürecini kolaylaştırmak için geliştirilmiş bir frontend web projesidir.

**EN:** Barınak Sitesi is a frontend web project developed to facilitate the adoption process for homeless animals to find warm homes, inform visitors about shelter activities, and streamline the adoption process.

---

## ✨ Özellikler / Key Features
- 🐕 **Dostlarımız / Our Friends:** Sahiplenilmeyi bekleyen hayvanların profillerini ve bilgilerini gösteren dinamik bir galeri. / A dynamic gallery showcasing profiles and information of animals waiting to be adopted.
- 📝 **Sahiplenme Formu / Adoption Form:** Kullanıcıların online olarak sahiplenme başvurusu yapabileceği kullanıcı dostu bir form. / A user-friendly form where users can apply for adoption online.
- ❤️ **Destek & Bağış / Support & Donation:** Barınağa nasıl destek olunabileceğine dair bilgi bölümü. / An information section on how to support the shelter.
- 📱 **Tam Duyarlı / Fully Responsive:** Mobil, tablet ve masaüstü cihazlarla tam uyumlu arayüz. / Interface fully compatible with mobile, tablet, and desktop devices.
- 🎨 **Modern UI/UX:** İç açıcı renk paleti ve kolay navigasyon ile geliştirilmiş kullanıcı deneyimi. / Enhanced user experience with a welcoming color palette and easy navigation.
